## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Project requirements

- Starmore Tools is free to use and does not require an account.
- All tool processing must run in the browser. Do not add processing servers or paid services.
- Implement each tool as a React component in `src/components/tools/` and register it in `src/data/tools.ts`.
- Keep the experience clean, mobile-first, and fast.
- Do not add dependencies that require API keys or payment.
